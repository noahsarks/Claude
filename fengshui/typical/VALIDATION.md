# 典型建筑验证（v0.6 → v0.8）

**目的**：规则改完之后，先在少数几个「信息弄得清楚」的点上看改动的方向对不对，
而不是又去跑几千个样本。样本见 `sites.yaml`——八个点，**每个点的坐向都注明出处**，
无据的（二里头）标 null 并只作对照。

结果是：**这一轮最大的发现不是规则，是一个 bug。**
补《水龙经》平洋法的时候，第一步「分辨支与干」在所有平原点上都判不出来，
追下去发现汇流网络在平地上整个断掉了。修完之后，八个点的分数变化
比四条规则改动加起来还大 2.4 倍。下面先说 bug，再说规则。

---

## 一、汇流网络在平地上断了（v0.8 修）

### 怎么发现的

《水龙经》卷 671 總論一开宗明义：「以通流大水為行龍而為幹，溝渠小水為割界而為支。
**穴法取支不取幹**」，并说「余以支幹之說，為水龍第一義」。
实现这一条要先在穴周分出「干」和「支」。结果八个点里五个报「俱无」——
包括紧邻洛河的汉魏洛阳故城与隋唐洛阳城。

查下去：洛阳一带 4 km 内最大汇水面积只有 **4.35 km²**，
而洛河实际流域上万 km²。3×3 瓦片区（89,530 km²）内最大流域仅 **195 km²**，
占区域面积 0.22%。

### 病因

`Region._drainage()` 里，填洼用形态学重建，**会造出严格水平的平面**；
随后的 D8 定向是

```python
best = np.zeros((h, w), np.float32); di = ... - 1
drop = (fill - nb) / dist
upd  = drop > best          # best 初值 0 ⇒ 要求严格正落差
```

平面上八邻域落差全为 0，`drop > 0` 不成立，方向保持 −1，**汇流在此中断**。

实测：单瓦片 **6.39%** 的内部格没有下游，
且其中 **100%** 是「邻域最低高程等于自身」的严格平地。

**平原正是平地最多的地方**，所以这个缺陷恰好在最需要水系的地方最严重。

### 改法

Garbrecht & Martz (1997) 的双梯度平地导流：在平地上叠一层极小的合成坡降
（背离高地 + 趋向出口，出口权重 2 倍，ε=1e-3 m/步），在 `fill+ε·梯度` 上重排 D8；
仍有平手的残余格再做一次多源 BFS 兜底（步数严格递减，不成环）。

### 外部校核（`river_check.py`）

**「变了」不等于「对了」**，所以用 OSM `waterway=river` 作独立参照：
取真实河道上的采样点，量它到「模型判出的水道」的距离。

| 区域 | | n | 中位距离 | 均值 | <240 m 占比 | 水道格数 | acc 最大 |
|---|---|---|---|---|---|---|---|
| 洛阳盆地（平原） | 修前 | 391 | **2121 m** | 2346 m | 9.0% | 7,527 | 27 km² |
| | 修后 | 391 | **304 m** | 597 m | **45.3%** | 30,426 | 219 km² |
| 燕山南麓（山地） | 修前 | 1185 | **1106 m** | 2753 m | 23.8% | 8,905 | 49 km² |
| | 修后 | 1185 | **212 m** | 569 m | **52.0%** | 22,753 | 497 km² |

两区都大幅改善，且**修前平原确实比山地差一倍**（2121 vs 1106 m），
与「平地导流失效」的病因判断一致。这是本项目少数几次拿外部数据做的校核。

### 影响面

`d_water`、`bank`、`sinuosity`、`lock`、`river_km2`、`dh_water`、`water_converge`、
`mt_water`——**引擎里所有涉水的量，此前都算在一张平均偏离真实河道 1–2 km 的网上。**

`drainage_effect.py` 把「修 bug」与「改规则」分开量（同一套 v0.6 规则跑在修前/修后网络上）：

## 二、规则改动（v0.7 三条 + v0.8 一条）

| 改动 | 原文依据 |
|---|---|
| 删 `balance`（龙虎左右对称） | 「青龙蜿蜒，白虎驯頫」给左右规定了**不同**形态；全文无一处要求对称 |
| 明堂补水项，四级序 | 「明堂者，穴前水聚处也」「以聚水为上，横抱次之，朝水又次之……顺流者又次之」 |
| R3 环带 0.3–3 km → 0.1–4 km | 「不拘远近，俱名有情」 |
| **新增平洋法** | 《水龙经》卷 671–674，见下 |

### 平洋法（B7）实现了什么

原文最要紧的一句是「後世言地，知山之龍而不知水之龍，
遂使平洋水局之地，**傅會山龍之妄說**」——拿山龙判据评平原，原文自己就点名说是错的。

四项，出处逐条可查：

| 项 | 原文 | 实现 |
|---|---|---|
| **支干相扶** | 「以通流大水為行龍而為幹，溝渠小水為割界而為支。穴法取支不取幹」 | 4 km 内最大汇水为干，1 km 内小汇水为支。**支干相扶 1.00；只有其一 0.40**——原文说「小幹無支……必久而後發；支龍無幹……氣盡易衰」，**没有把这两者互相排序，故给同值，不臆造高下** |
| 干水回头环绕 | 「大江大河一二十里而來，不見回頭環繞……決不結穴，直至環轉回顧之處，方是龍脈止聚」 | 干水在 24 个方位扇区中的占据比例 |
| 屈曲 | 「水法不拘去與來，但要屈曲去復迴，**三回五度**轉顧穴」 | 沿河道上下游各 1.2 km 数转向反复次数 |
| 澄清停蓄 | 「澄清停蓄甚為佳，傾瀉急流有何益」 | 河道纵比降 |

权重 .40/.20/.25/.15。**只有「支干第一」有原文依据**
（「余以支幹之說，為水龍第一義」），其余三项之间的比例是估值。

**势与形在平洋换了对应物**，这不是我的类比，是卷 671 的原话：
「以幹龍繞抱，取**外氣**形局；以支龍正息交會，取**內氣**孕育」——干即势，支即形。
故平洋模式下 `shi` 用干、`xing` 用支，不再拿玄武充势、拿贴身龙虎充形。

**平洋权重按原文重排**：「行到平洋莫問蹤，只看水繞是真龍」「平陽大地無龍虎」——
玄武与护龙在平洋归零，其 0.14 全给平洋项。藏风保留 0.03（《水龙经》未论藏风，
不能借它的名义删《葬经》的条目）。

**新增一条门槛级凶格**：干水散气。「幹水斜行，似有曲折，而非環抱，
又無支水，以作內氣，**總不結穴**」——三条件同时成立才算，罚重与五不葬同量级。

### 平洋法也会不判

修完 bug 之后，洛阳一带 4 km 内最大汇水仍只有 20 余 km²——
**够分「支」「干」的相对高下，但远不是《水龙经》说的「大江大河」。**
所以设了下限：若 4 km 内最大汇水不足成道阈值的 4 倍（8 km²），
判「不判(汇流网络未见干水)」，`score()` 把该项权重按比例摊回其余各项。

报「俱无」就是拿「没检测到」冒充「没有」——与明堂水项、与我在 `../audit/`
里批评 suangua 的，是同一类错误。

### 检验：结果是干净的零

这八个点都是**已知被选中**的地方（都城、帝陵、遗址）。
若模型有效度，它们应当系统性地高于自己的邻域。

| | v0.7（坏网络） | **v0.8（修好后）** |
|---|---|---|
| 高于本地中位 | 5/8 | **3/8** |
| 分位均值 | 0.615 | **0.515** |
| 二项单侧 p | 0.363 | **0.855** |
| t 单侧 p | 0.134 | **0.431** |
| Wilcoxon 单侧 p | 0.219 | **0.492** |

**分位均值 0.515——零假设是 0.500。** 这不是「不显著」，是**恰好落在随机上**。

### 修前修后两批分位几乎不相干

| | |
|---|---|
| Spearman rho | **0.287**（p=0.490） |
| Pearson r | 0.387 |
| 平均绝对分位变化 | **24 个百分点** |

两批数在同样的八个点上，只差一个 bug 修复，排序相关性 0.29。
**这说明 v0.7 那批数几乎不含信息**；同时也说明，
在有别的东西来校 v0.8 这批之前，它自己的可靠性同样是未知的。

### 因此撤回三条（都是我上一轮刚写下的）

**① 「二里头 27%——本轮唯一方向明确为负的结果，不绕过去」——撤回。**
修好水系后是 **50%**，正正好好落在邻域中位上。
那个 27% 是坏网络的产物：二里头 4 km 内本来就找不到水道，
坏网络下更找不到，水相关的每一项都被压低。
我当时特意写了「不能把它当噪声处理」——**结果它就是噪声。**

**② 「上海中心 98% 是假的」——结论对，但理由只对了一半。**
我当时归因于背景 SD 只有 0.021（陆家嘴邻域在 DEM 里是一块平板），
这条现在仍然成立（v0.8 的 SD 是 0.020）。
但 98% 这个数本身也是坏网络造出来的——修好后是 **48%**。
所以「分位要与离散度一起报」这条方法论结论保留，
**但那个 98% 不该拿来当例子**。

**③ 「长陵是唯一七项全高的点」——不再成立。**
v0.8 下长陵水口 0.240（v0.7 是 0.706），分位从 97% 落到 76%。
它仍然是原始分与分位都靠前的点之一，但「七项全高」这个说法作废。

### 唯一被加强的一条

**永定陵现在是八个点里本地分位最高的（84%）。**
上一轮我已经撤回过「模型给它低分正说明它按五音姓利定向」这个读法；
修好水系之后，它不但不低，**还是全集最高**。原来的读法错得比我上次说的更彻底。

## 六、这一轮的净账

**修好的**：

1. 汇流网络在平地上断了七个版本，现已修复并经 OSM 外部校核（中位偏离 2121→304 m）
2. 《水龙经》平洋法（B7）补上，四项逐条可回溯，判不出干水则不判
3. 「聚水」档第一次触发（长陵）——上一轮记的「从未取到的档位等于没验证过」已兑现

**变坏的（指对模型有效性的判断）**：

4. 八个已知被选中的点，在自己邻域里的分位均值 **0.515**——干净的零。
   坏网络时是 0.615（也不显著）；修好之后连那点虚高也没了。
5. 上一轮三条结论里两条被自己的修复推翻（二里头的负结果、上海中心的例子）
6. 明堂扇区 ±45° 的敏感性从七点两翻档变成**七点五翻档**

**这一轮真正学到的**：

- **模型自己跟自己比，查不出模型的错。** 五点验证、三区分层、尺度扫描、噪声测量、
  消融实验，五种检验全部只比较模型的输出，七个版本没发现一个把河流位置算错 2 公里的 bug。
  第一次拿外部数据（OSM 河道）校中间产物，当场就出来了。
- **一个数据缺陷能凭空造出「发现」**。二里头那个 27%，我不但没当噪声，
  还专门写了一段说不能当噪声。它就是噪声。
- **下一步不是加规则。** 涉水的旧结论全部作废，得先用新网络把洛阳、关中、
  三区分层重跑一遍，才知道站在哪里。
