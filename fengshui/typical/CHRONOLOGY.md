# 堪舆方法编年 —— 一份变更日志

把手上全部文献按可考年代排开，看后代到底改了什么。

**语料底本**：《欽定古今圖書集成·博物彙編·藝術典·堪輿部》651–680 卷，
清康熙末编、雍正四年（1726）刊。全文已入库 `../masters/corpus/gjtsjc/`。

**这个底本给出一条硬截止线**：凡该书三十卷中没有的方法，都是 1726 年以后的。
下文有一处关键判断就是这样得出的。

**断代原则**：术数文献托名极重（托郭璞、托杨筠松、托黄妙应、托管辂）。
凡有争议者标「托 X／实 Y」，**传统署名不作成书年代用**。

## 变更日志

### 底层（托汉—托晋，实唐宋成书）·《青烏先生葬經》《郭璞古本葬經》

**立**：

- 「葬者，乘生氣也」——目的论
- 「氣乘風則散，界水則止……故謂之風水」——**得水 > 藏风**的优先序
- 四勢：玄武、朱雀、青龍、白虎
- 五不葬：童、斷、石、過、獨
- 「千尺為勢，百尺為形」——**双尺度**

> 这一层定义了此后一千余年的全部框架。后世所有增补都在这个骨架上做。

### 640 · 唐 呂才《五行祿命葬書論》（卷 680 藝文）

**批判，非新增。** 但方法上是本编年里最现代的一条：

- 对**五音姓利**：无出处 + 姓氏后起无从配属 + 内部不自洽（《春秋》里陳同为水姓与火姓）
- 对**葬不擇日**：「今檢葬書，以己亥之日用葬最凶。謹按春秋之際，此日葬者凡有二十餘件」
  —— **基率检验**，与本项目的 Kvamme 增益是同类推理，早一千四百年

### 唐末—宋 · 楊筠松系（托名）

- 《撼龍經》《疑龍經》：九星形态辨龙
- 《青囊奧旨》《十二杖法》（顺逆缩缀开穿离没对截犯顿）

**新增：从「相地原则」下沉到「点穴操作」。** 十二杖法是具体的落钎手法。

### 唐宋 ·《管氏地理指蒙》（托三国管辂）

篇目九十余：相土度地、開明堂、四勢三形、遠勢近形、應案、擬穴、得穴、**擇向**、望勢尋形、水城……

**新增两点**：
1. 把相地拆成上百个可操作条目
2. **「擇向」作为独立步骤出现** —— 坐向从此与选址分离（对应 `../masters/analysis.md` 结论三）

### 隋唐—北宋 · 五音姓利（官方，与形势派并行）

姓氏声韵 → 利向，**与地形无关**。北宋皇陵一律「东南地穹、西北地垂」，
即头枕东南足抵西北，**与形势派通则正相反**。

**640 年已被吕才以内部不自洽证伪，仍官方行用四百年。**

### 1022 · 牛頭山之爭（卷 679 徐仁旺、吳景鸞传）

徐仁旺主张用牛頭山**前**地，丁謂定用**後**地：

> 坤水長流，災在丙午歲內；丁風直射，禍當丁未年中。（徐仁旺）
> 坤風側射，厄當國母離宮；坎水直流，禍應至尊下殿。（吳景鸞）

**意义**：现存最早的、**带否定样本**的形势判据实例。判据是「方位＋地形要素＋形态」的三元组。

### 宋 · 蔡元定《發微論》（1135–1198，年代确切）

聚散、向背、顺逆诸论。**新增：理论化**——从操作口诀转向原理阐述。

### 宋元 ·《黃妙應博山篇》（托唐，卷 666）

论龙、穴、砂、水、明堂、阳宅、平地。

**新增：「度」的概念**——「宽不至旷，狭不至逼，斯名全吉」。
此前只说「要有」，此处开始说「要多少」。

### 元末明初 · 劉基《堪輿漫興》（1311–1375，卷 669）

山祖、水源、北龙中龙南龙、枝干、真假、贵贱……

**新增：全国尺度的「三大干龙」框架。** 相地从此有了区域地理的上位结构。

### 明 · 繆希雍《葬經翼》（1546–1627，约 1600，卷 670）

**本项目 16 条规则里有 9 条出自这一部。** 也是全部语料中最系统的一部。

**新增三项：**

1. **穴病十五条** —— 貫頂、折臂、破面、墜足、綳面、飽肚、割腳、漏腮、
   虎蹲、龍踞、元武拒尸、朱雀騰去、前花、後假、左右詭落。
   **从「怎样是好」转为「怎样是坏」的诊断清单**，是判据形态的一次根本转变。
2. **明堂三层 + 水的四级序** ——「明堂者，穴前水聚處也」，
   分小明堂／中明堂／外洋大明堂；「以聚水為上，橫抱次之，朝水又次之，……順流者又次之」。
3. **水口按对象分级** ——「若結**都會**及作**帝王山陵**，必有北辰尊星坐鎮水口」。
   **原文自己就区分帝陵/都城与一般墓穴**，这印证 `../layering/` 的轴 1 不是外加的分类。

### 明 ·《陽宅十書》（卷 675–678）

論宅外形、福元、大遊年、穿宮九星、元空裝卦、開門修造、放水、論宅內形、論選擇、論符鎮。

**新增：阳宅独立成体系。** 但注意：**它一开始就是混的**——
宅外形属形势，福元／大游年／穿宫九星／元空装卦属理气，另有择日与符镇。
「形势与理气分家」这个说法对阳宅从来不成立。

### 明末清初 ·《水龍經》（卷 671–674，四卷共 500 余图）

**新增：平洋法。** 以水代山。

此前判据以山为主，平原无法适用。水龙经把「水」提升为独立的形势系统。

> **对本项目直接相关**：洛阳盆地、关中都是平原样本，
> 本应用这一支，而现有 16 条规则一条都不出自它。这是明确的缺口。

### 1726 · 《古今圖書集成》成书 —— **截止线**

全 30 卷中关键词出现次数（`term_trace.py` 实测，逐卷表见脚本输出）：

| 生氣 | 197 |
| 龍虎 | 134 |
| 水口 | 109 |
| 四勢 | 101 |
| 平洋 | 62 |
| 陽宅 | 43 |
| 得水 | 38 |
| 五音 | 31 |
| 藏風 | 29 |
| 三元 | 19 |
| 納甲 | 14 |
| **飛星** | **0** |
| **挨星** | **0** |
| **九運** | **0** |

> **「飛星」「挨星」「九運」在 1726 年的官方类书里一次都没有出现。**
>
> 该书是奉敕编纂的类书，堪舆部收了从青囊海角经到阳宅十书二十余种，
> 连符镇、择日都收，也收了整整一卷反对风水的文章（卷 680 藝文）。
> 收录标准显然不是「只收我们认可的」。飞星若已成体系，没有理由不收。

**必须说清楚的限定**（不然这条结论会被读过头）：

「三元」出现 19 次，**不是零**。逐条看过，它们是三类，都不是玄空飞星：

1. **三元甲子配福元**——《陽宅十書》卷 675/677「三元甲子福德」「《福元》內三元起手」，
   《管氏指蒙》卷 660「一白、二黑……九紫，分三元、六甲。上元甲子生人，一十起三碧……
   不問上中下三元皆順行九宮」。**输入是人的生年，不是坐向；九星順行九宮，不排山盘向盘。**
2. **书名**——卷 651《三元宅經》《三元經》、卷 680《三元衡鑑》《五音三元宅經》。
3. **一处外部指引**——《水龍經》卷 672：「此卷『吉凶之妙，但言其體，未及其用，
   **當合《三元九宮》推之**，禍福不爽矣。』」

第 3 条最要紧：**1726 年以前确实存在一个叫《三元九宮》的东西，水龙经明确引它作配套。**
所以不能说「三元九宫系统当时不存在」。

**能说的是**：三元九宮当时是**年命/福元一路**的方法（上中下元甲子 → 九星顺行九宫 → 配人），
而**清中叶蒋大鸿—章仲山那一套「坐向度数 → 挨星起星 → 山盘向盘双飞 → 二十四山分阴阳顺逆」
的排盘术，在这三十卷里一个字都没有**。

**推论**：用三元九运**飞星**去评 1726 年以前的建筑，是把清中叶的方法倒推。
这一条以前只是我的判断，现在是语料实证——但实证的边界就到「飞星/挨星/九运三词全零」为止，
不能扩大成「三元系统整个是清代才有的」。

### 清 · 蔣大鴻 → 章仲山《陰陽二宅錄驗》（1813–1838）

**新增：理气成为主导。** 三元九运 + 挨星 + 山向飞星。

章仲山的逐案记录体：坐向（含兼线）+ 元运 + 形势 + 断语 + 应验。

**但形势并未被废除，而是降为「凑合」项。** 王则先补阐说得最明白：

> 玄空五行之吉凶，**必与实地形峦相凑合，其验乃神**……**苟无路气直冲，甚验亦微**。

即：**理气定性质，形势定强度，二者是乘性关系。**
（这也是 `masters/cases/B02` 那个内部一致性检验的结论来源：
上山下水断语必负 7/7，而旺山旺向只有一半正 2/4——那一半的修正项全是形势。）

### 清末民初 · 沈竹礽（1849–1906），《沈氏玄空學》1927 刊

**新增：可公开验证的算法。** 破章氏之秘，用公开规则复算其案例集。

本项目挨星实现的四端点互证（沈氏表 ↔ fscalc ↔ Horosa ↔ 章仲山原案）即以此为基准。

### 20 世纪 · 港台分化

吳師青（1893–1980，《天体历》把真实天文历算纳入）、
孔昭蘇（1902–1979）、談養吾（1890–1970s，**中年公开否定自己前半生所学**，改宗六法）、
曾子南（1907–2006，以六十四卦立向）。

**变动：分化为互相矛盾的诸派。** 同一坐向，沈氏 / 中州 / 谈氏六法给出不同盘。

### 当代

- **学术**：王其亨等《風水理論研究》—— 建筑测绘 + 样式雷图档，反推古人实际依据
- **软件**：全部是理气排盘器，**无一接 DEM**（见 `../audit/`）
- **实践**：城市从业者用建筑相对高度替代山水，判断零和相对（见 `../masters/cases/A04`）

## 汇总：哪些沿用、哪些是后人加的、加得对不对

### A · 自古沿用、从未变过（《葬经》→ 今）

| 条目 | 首见 | 状态 |
|---|---|---|
| 乘生气的目的论 | 葬经 | 沿用 |
| 四象框架（玄武朱雀青龙白虎） | 葬经 | 沿用，明代细化出反面（拒尸/腾去/衔尸/嫉主） |
| **得水为上，藏风次之** | 葬经 | 沿用。**这是权重序关系的唯一原典依据** |
| 千尺为势、百尺为形 | 葬经 | 沿用 |
| 五不葬（童断石过独） | 葬经 | 沿用 |

### B · 后人新增，且经受住了时间（应当保留）

| 新增 | 时代 | 评价 |
|---|---|---|
| 点穴操作法（十二杖） | 唐末—宋 | 尺度太细（米级），DEM 用不上，但概念无问题 |
| 择向独立成步 | 唐宋（管氏） | **正确且重要**——与民族志四案一致 |
| 「度」的概念（宽不至旷狭不至逼） | 宋元（博山篇） | 正确，非单调判据的来源 |
| 三大干龙 | 元末明初（刘基） | 正确，提供区域上位结构 |
| **穴病诊断清单** | 明（葬经翼） | **正确且是形态转变**——从正面标准到反面清单 |
| **明堂三层 + 水四级序** | 明（葬经翼） | 正确。**本项目 v0.7 才补上水项** |
| **水口按对象分级** | 明（葬经翼） | 正确。**尚未实现** |
| **平洋法** | 明末清初（水龙经） | 正确且必要。**本项目完全缺失** |

### C · 后人新增但有问题

**① 五音姓利（隋唐—北宋官方）**

- 输入是**姓氏声韵**，与地形无因果关联
- **640 年已被官方学者吕才以内部不自洽证伪**（同一诸侯国在不同经典里归属不同五行）
- 仍行用四百年，且决定了北宋皇陵的朝向
- **对本项目的影响**：巩义宋陵在晋南豫北样本内，纯地形模型对它必然失败，
  而这不是模型的缺陷（见 `../masters/cases/A05`、`A10`）

**② 三元九运飞星（清）**

- **1726 年官方类书三十卷中「飞星」「挨星」「九运」出现 0 次**——语料实证
- 把判断从地形转向「建成年 + 坐向度数」，与形势判据无因果关联
- **各派挨星互不相容**：沈氏 / 中州 / 谈氏六法给出不同盘（`../audit/` 已量化沈氏 vs suangua 差异达 72%）
- 不是说它错，而是说：**它是一套另外的东西，不能与形势判据混算**（`../layering/` 轴 3）

**③ 托名本身就是一个方法论问题**

《葬经》托郭璞、《撼龙经》托杨筠松、《博山篇》托黄妙应、《管氏指蒙》托管辂、
《雪心赋》托卜则巍。

**托名使方法看起来比实际古老，掩盖了真实的演变过程。**
若按署名排序，会得出「东汉已有完整体系、后世只是注解」的错误图景；
按实际成书排序才看得出：**核心判据的系统化其实集中在宋—明，而明代（葬经翼）是最大的一次增补。**

### D · 本项目自己加的（也是「后人修订」）

| 项 | 状态 |
