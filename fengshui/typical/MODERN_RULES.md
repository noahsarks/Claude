# 现代版规则（v1.0）

在编年梳理（`CHRONOLOGY.md`）与逐条核对原文（`../rules_audit/`）之后，
把规则重新整理成一份带**出处分级**与**适用条件**的清单。

与 `../rules_luantou.yaml` 的关系：那份是**过程台账**（含每一次撤回与失败），
本文是**结论**。两者都保留——台账证明结论是怎么来的。

## 一、出处分级

每条规则标一个等级。**等级不是可信度，是「谁说的、什么时候说的」。**

| 级 | 含义 | 处理 |
|---|---|---|
| **A** | 《葬经》层，自古沿用未变 | 保留，作为骨架 |
| **B** | 后人新增，经受住时间，且原文可核 | 保留 |

| **D** | 本项目所加，原典无据 | 删，或标为估值 |

## 四、C 级：有问题的，单列不并入

### C1 · 五音姓利

- 输入是姓氏声韵，与地形无因果关联
- **唐 640 年吕才已以内部不自洽证伪**（《春秋》中陳同为水姓与火姓）
- 仍行用四百年，决定北宋皇陵朝向

**处理**：不作为判据。但**必须作为样本标签**——
凡按五音姓利定向的遗址（北宋皇陵为主），形势判据对它天然不适用，
应从形势验证集中剔除或单列。

### C2 · 三元九运飞星

- **语料实证**：《古今图书集成·堪舆部》30 卷中「飞星」「挨星」「九运」出现 **0 次**
  （`term_trace.py`；同表「明堂」313、「龙虎」134、「水口」109）。
  该书奉敕编纂、收书二十余种、连符镇与反对风水的文章都收——飞星若已成体系没有理由不收
- **限定**：「三元」出现 19 次，非零。逐条核过，是三类：三元甲子配**福元**（输入人的生年，
  九星顺行九宫，不排山向盘）、书名、以及《水龙经》卷 672 引《三元九宫》为配套。
  故**不能说三元系统是清代才有**；能说的是**「坐向度数 → 挨星起星 → 山盘向盘双飞」
  这套排盘术在三十卷里一个字都没有**。详见 `CHRONOLOGY.md`
- 判断依据是「建成年 + 坐向度数」，与地形无因果关联
- 各派挨星互不相容（沈氏 / 中州 / 谈氏六法）

**处理**：**与形势判据分算，永不混合。**
本项目的挨星实现已四端点互证（沈氏表 ↔ fscalc ↔ Horosa ↔ 章仲山原案，
下卦 216/216 与 6/6），可以放心用于**1726 年以后**的对象。
**用于 1726 年以前的建筑即为倒推。**

### C3 · 托名

《葬经》托郭璞、《撼龙经》托杨筠松、《博山篇》托黄妙应、
《管氏指蒙》托管辂、《雪心赋》托卜则巍。

**处理**：一切规则的 `era_valid` 以**实际成书年代**为准，不以署名为准。
按署名排序会得出「东汉已有完整体系」的错误图景；
按实际成书排序才看得出**系统化集中在宋—明，明代《葬经翼》是最大一次增补**。

## 六、适用条件（每条规则必须携带）

依 `../layering/dispatch.yaml`，每条规则带四个字段，不匹配则**不参与计算**（不是降权）：

```yaml
对象:   [阴宅] / [阳宅] / [城址] / 通用
era_valid: [起, 止]        # 以实际成书年代为起点
尺度:   [下限 m, 上限 m]
语式:   判定式 | 祈使式     # 祈使式只用于择址，不用于断验已建成的遗址
```

**当前 16 条规则全部是「对象=阴宅」**，而验证样本 89.5% 非阴宅——
这个不匹配已由实测确认（`../layering/stratify_results.md`：
古墓葬层增益 −0.200，是四类官方类别里唯一为负的）。

## 七、现在能说什么、不能说什么

**能说**：

1. 规则的**出处**现在逐条可回溯到原始文本（`../rules_audit/quote_check.py`，13/16 条核实属实）
2. 挨星算法**正确**，四端点互证
3. 磁偏角处理**正确**，且量化了不做校正的后果
4. **玄空飞星是 1726 年后的方法**——语料实证，非推断

**不能说**：

1. 不能说这套规则**有预测效力**。效应量 +0.043 ≈ 1 km 位移噪声 0.042，信噪比约 1:1
2. 不能说洛阳的 +0.564 是证据（关中同参数 −1.400，已撤回）
3. 不能说分层能解释矛盾（对象、地貌、起伏三种控制都做过，矛盾在层内原样存在）
4. **平原样本的结论一律存疑**——平洋法（B7）完全缺失，而洛阳关中都是平原
