## 二、两套规则怎么定的

### ① 现代版 v1.1

引擎 v0.8 原样，即 `../typical/MODERN_RULES.yaml` 的 A 级 5 条 + B 级 13 条，
C 级（五音姓利、玄空飞星）不并入，D 级权重标为估值。
平洋模式下玄武／护龙权重归零、势形改用干／支（《水龙经》B9、B10）。

### ② 「古籍中最可靠的版本」＝《葬經翼》（约 1600）

**为什么是它，而不是《葬經》。** 依 `../typical/corpus_stats.py` 的实测：
《古今图书集成·堪舆部》三十卷里技术文献 307,025 字，**66.1% 是托名**，
年代确定的只有 **17.2%**——而这 17.2% 就是繆希雍《葬經翼》与《陽宅十書》两部。

《葬經》题郭璞，不见于《隋志》《唐志》，《宋志》始著录，年代只能定到「唐宋」，
作者不可考。**它最古老，但它不是最可靠。** 论年代可靠，
技术文献里第一部是《葬經翼》：繆希雍生卒可考（约 1546–1627），本书见于其著录，
且本项目 16 条规则里有 9 条出自这一部。

所以 ② 只用卷 670 一部书：

| 用 | 出处篇目 |
|---|---|
| 玄武 | 四獸砂水篇、原勢篇、察形篇 |
| 护龙 | 四獸砂水篇「青龍蜿蜒，白虎馴頫」「環抱有情，不逼不壓」 |
| 向背 | 四獸砂水篇 |
| 明堂（含水的四级序） | 明堂篇「明堂者，穴前水聚處也」 |
| 水口 | 水口篇 |
| 凶格七条 | 穴病篇（拒尸、坠足、折臂、割脚、虎蹲、龙踞、朱雀腾去） |

| 不用 | 理由 |
|---|---|
| 得水分量 | 指标组合出自《博山篇·論水》与无定河实证，非本书 |
| 藏风分量 | 「藏風」出自《葬經·氣感篇》，非本书 |
| 五不葬（过山、独山） | 《葬經》，非本书 |
| **平洋法全套** | 《水龍經》，17 世纪，**本书成书约 1600，无此内容** |

**最后一条是这次对照的要害**，见第五节。

## 三、先解决一个数据问题：松花江在 DEM 里看不见

实现平洋法第一条「以通流大水為行龍而為幹」时，哈尔滨全域报「不判」。
原因不是引擎错，是数据边界：**DEM 汇流累积只统计瓦片内部汇入的面积**，
松花江上游在瓦片之外，所以瓦片里怎么算它都不是「大水」。

把阈值调低去迁就坏数据是错的。做法是**拿外部数据给「幹」**：
取 OSM `waterway=river/canal/stream/ditch`（557 条、42,038 节点），
按 **waterway=river 且同名总长 ≥ 90 km** 判为幹——不预设名字，让数据自己分。
判出来的是：**松花江、阿什河、拉林河、呼兰河、少陵河**（另加 canal 肇兰新河的 river 段）。
stream/ditch 正对应原文的「溝渠小水」，做「支」。

这是引擎 v0.9 的加法式改动（`attach_external_rivers` + `_pingyang_ext`），
**默认路径不变**——`../typical/run.py` 八个点的分数与 v0.8 逐位相同，已回归验证。

另有一处顺手修的：OSM 折线的顶点密度因录入者而异，直接在原顶点上数「三回五度」
数到的是数字化精度不是河道形态（市中心马家沟河原顶点给出 30 次转向）。
改为先按 200 m 等距重采样再数。

## 四、哈尔滨的地形底子

4012 个有效点，1.5 km 步长，范围 45.35–46.15°N / 126.00–127.30°E。

| | |
|---|---|
| 地貌 | **平原 89.1%**，破碎沟壑 5.2%，丘陵台塬 5.1%，山地 0.6% |
| 引擎模式 | **平洋 89.5%**，山龙 10.5% |
| 3 km 起伏度 | 中位 **40 m**，P90 140 m |
| 平洋支干 | 俱無 60%，有幹無支 21%，有支無幹 13%，**支幹相扶 6%** |

一句话：**哈尔滨是一块平地。** 起伏中位 40 m，山龙那一套在这里基本无处着力；
仅东南角（阿城—玉泉—小岭，张广才岭西麓）有真实地形。

## 六、分歧是系统性的，来源可以定位

按平洋支干类别分层看分位差（正＝现代版更看好）：

| 支干判定 | n | 分位差均值 | 现代版均分 | 《葬經翼》均分 |
|---|---|---|---|---|
| **支幹相扶** | 235 | **+0.213** | 0.360 | 0.314 |
| 有幹無支 | 846 | +0.081 | 0.300 | 0.305 |
| 俱無 | 2420 | −0.002 | 0.308 | 0.330 |
| **有支無幹** | 511 | **−0.221** | 0.254 | 0.342 |

按地貌分层：山地 +0.228、破碎沟壑 +0.124、丘陵台塬 +0.105、**平原 −0.015**。

**读法**：分歧不是随机噪声，它精确地落在《水龙经》新增的那一条上。
凡有大河环抱又有支水割界的地方，现代版加分而《葬經翼》看不见；
凡只有小水没有大河的地方，《葬經翼》给高分（它只看砂的形态），现代版扣分
（原文「支龍無幹，其效雖捷，而氣盡易衰」）。

《葬經翼》本前 10% 里有 **68% 落在平原**、26% 是「有支無幹」；
现代版前 10% 平原占 57%、支幹相扶占 15%。

### 这正是《水龙经》点名的那件事

> 後世言地，知山之龍而不知水之龍，遂使平洋水局之地，**傅會山龍之妄說**
> ——《水龍經》卷 671 序

哈尔滨 89.5% 的面积是平洋。把一部成书约 1600 年的**纯山龙**著作用在这里，
原文自己在一百年后就点名说这是错的。
本次对照没有替古人打补丁，**照它本来的样子跑**，于是把这句批评变成了一张图：
第三幅图上那片贯穿平原的红色，就是「傅會山龍」的分布。

**所以这次对照的结论不是「哪套规则更准」，而是**：
最可靠的古籍也有它的适用边界，而这个边界是**地形**，
不是年代可靠性能补上的。年代最可靠的那部书，恰好是对哈尔滨最不适用的那部。

## 七、这张图不能当什么用

1. **不能当选址建议。** 同一套现代版规则在八个已知被选中的古代样本上，
   本地背景分位均值 **0.515**（零假设 0.500），三种检验全不显著
   （`../typical/VALIDATION.md`）。**分数没有经过效度检验。**
2. **坐北朝南是假设。** 明堂水项依赖坐向；换一个坐向，明堂那一项会变。
3. **格网 1.5 km，不出单点结论。** 城址的单点分本项目已整体撤回。
4. **「幹」的判据依赖 OSM 覆盖度。** 90 km 这个门槛是我定的，
   原文只说「通流大水」，没给数。
5. 现代版与《葬經翼》本的绝对分不可直接比大小——两套规则的分量数目与权重不同，
   同一绝对刻度只用于看空间格局，比较请看第三幅的**分位差**。
