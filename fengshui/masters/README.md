# 近二百年风水师名录与案例拆解（1826–2026）

## 这份东西是干什么的

前面几轮我们把引擎和考古基准对撞过，结果是效应 +0.043、1 km 位移噪声 0.042，
信噪比约 1:1；洛阳 +0.564 与关中 −1.400 互相矛盾。
读商业与开源软件后又发现：**现存最完整的峦头实现把峦头当人工勾选表单，不当计算。**

那么剩下一个没做的外部检验：**真人是怎么做的。**
不是古籍怎么说，是近二百年里有名有姓的术者，面对具体一块地，
实际看了什么、算了什么、下了什么断语。

本目录做三件事：
1. `roster.yaml` —— 1826–2026 的风水师名录，含学派、传承、方法论、代表作、**证据等级**
2. `cases/` —— 能找到原始记述的真实案例，逐案拆解
3. `analysis.md` —— 全部案例的统计，回答「我们的地形引擎在真实实践里占多大比重、能不能被这些案例检验」

## 证据分级（贯穿全部条目）

| 级 | 含义 | 可核验性 |
|---|---|---|
| **A** | 第三方独立记录：学术田野调查、建筑测绘、同时代档案 | 高。观察者与被观察者分离 |
| **B** | 术者本人或门人所撰案例集，原文尚存 | 中。过程可信，**结果自述，不可核验** |
| **C** | 媒体/传记转述，事件本身可查（人、地、时确定） | 低。细节多经润色 |
| **D** | 无出处的传说、排行榜、软文 | 无。**只登记不采信** |

**这条分级是本目录最重要的部分。** 这个题目的互联网语料被软文与排行榜主导，
不分级就等于把广告当数据。凡 D 级，本目录只记其存在，不进案例库。

## 本次检索的实际边界（必须先讲清楚）

**拿到了：**
- Ren, Youcao. *Feng Shui: Changing Rules and Meanings*（PhD, University of Sheffield）
  的完整正文（本地 `thesis.txt`，48 万字）。其第五章是 2014–2017 年在浙江与河南
  的一手田野观察，**是本目录 A 级案例的主要来源**。
- 各学派传承脉络的中文二手资料（阐微堂、搜狐、维基），用于 `roster.yaml`。

**没拿到：**
- **章仲山《阴阳二宅录验》/《宅断》、沈竹礽《沈氏玄空学》的全文。**
  archive.org 有《增广沈氏玄空学》（`zengguangshenshi0000shen`，448 页），
  但属借阅馆藏，`_djvu.txt` 返回 401；360doc 上转载的宅断案例页对本环境 403；
  知乎专栏 403；百度百科连接重置。
  archive.org 全文检索命中的只有香港旧报纸（華僑日報、大公報、工商日報、循環日報），
  但其竖排繁体 OCR 完全不可用（实测下载 `NPWK19900620_djvu.txt`，「風水」命中 0 次，
  正文是「小 司 要 总 全 习 记」这种乱码）。
- 因此**清代案例库目前只有条目与出处，没有原文**。这些条目在 `cases/index.yaml`
  中标为 `text_retrieved: false`，并注明去哪里取（心一堂重印本、archive.org 借阅）。
  **本目录不会替这些案例编造原文。**

## 案例拆解的模板

每个案例文件按同一 schema 拆，字段的设计目标是**能不能拿来检验我们的引擎**：

```yaml
id / master / school / date / place / coords_known / evidence_grade / source
observed:            # 术者当场实际观察到什么
  terrain: []        #   峦头项（山、水、砂、明堂、层数……）
  liqi: []           #   理气项（坐向度数、元运、生辰、择日……）
  social: []         #   社会项（邻里、族群、客户诉求……）
rule_invoked:        # 援引了什么规则（原话优先）
judgment:            # 断语
outcome_claimed:     # 声称的应验（谁说的、可否核验）
decision_driver:     # 最终拍板靠的是哪一项 ← 关键字段
testable_by_us:      # 我们的 DEM 引擎能否复算
maps_to_component:   # 对应引擎的哪个分量
```

`decision_driver` 是整个拆解的重点。很多案例里，术者观察了一大堆东西，
但**真正决定结论的只有一两项**——找出那一两项，才知道该往引擎里放什么。
