# A05 · 五音姓利法与北宋皇陵（历史案例，方法论反例）

| | |
|---|---|
| 时代 | 北宋（960–1127） |
| 地点 | 河南巩义宋陵（永安陵、永昌陵、永熙陵、永定陵、永昭陵、永厚陵、永裕陵、永泰陵） |
| 证据等级 | **A** —— 陵墓实体存在、方位可实测；方法见载于宋代文献与后世研究 |
| 为何收入本目录 | 它是一个**方法论反例**：一整套皇家陵寝的朝向由**姓氏读音**决定，与地形无关 |

## 方法

五音姓利：把姓氏按声韵归入宫、商、角、徵、羽五音，各音对应利某方位。
赵姓属**角音**，利**壬丙**方向 —— 故北宋皇陵一律**东南地穹、西北地垂**，
即**头枕东南、足抵西北**，与「背山面水、坐北朝南」的通行形势原则**正好相反**。

## 对本项目的意义 —— 这是一条硬约束

`testable_by_us`: **是，而且它预言我们必然失败。**

巩义宋陵位于**晋南豫北**一带——**正是我们此前采样的区域之一**。
一个纯地形模型对这批陵墓必然给出低分或错误朝向，
**而这不是模型的缺陷，是这批遗址本来就不由地形决定。**

推论：**用「历史高等级遗址」当正样本这件事本身有系统性问题。**
样本里混着不同择址范式（形势派、五音姓利、政治军事考量、漕运便利），
把它们合起来当同一个「风水好」的标签，等于把几个不同的目标函数平均掉。

这为此前「洛阳 +0.564 / 关中 −1.400 互相矛盾」提供了一个候选解释：
**不是模型不稳，是两地正样本的择址范式不同。**
下一步的单因子诊断应当按**朝代与陵墓类型分层**，而不是把古迹一锅煮。
