# A09 · 管輅论毋丘儉墓（三国魏，约 255 前）

| | |
|---|---|
| 术者 | 管輅（209–256），魏平原术士 |
| 对象 | 毋丘儉墓（毋丘儉，魏將，255 年起兵败死，夷三族） |
| 记录 | 《三國志·魏志·管輅傳》，收入《古今圖書集成·堪輿部》卷680「紀事」 |
| 记录等级 | **A**（记载出自正史） / 应验为**事后追记** |
| 语料 | `../corpus/jishi.txt` |

## 原文

> 輅隨軍西行，過毋丘儉墓下，倚樹哀吟，精神不樂。人問其故，輅曰：
> 「林木雖茂，無形可久；碑誄雖美，無後可守。
> **元武藏頭，蒼龍無足，白虎銜尸，朱雀悲哭，四危以備，法當滅族**，
> 不過二載，其應至矣。」卒如其言。

（「元武」即玄武，避康熙諱作元武。）

## 为什么收这一条

**这是四象（玄武/青龙/白虎/朱雀）作为一套诊断判据的最早成条记载之一，
而且它是以「四项全缺 → 灭族」的形式给出的。**

我们的引擎里，`xuanwu`（背山）、`hulong`（左右护砂）、`mingtang`/朝案（前方）
这三个分量，其古典依据通常追到《葬經》「玄武垂頭，朱雀翔舞，青龍蜿蜒，白虎馴頫」。
本条是同一套判据用于**具体一座墓的实际判词**，而非泛论。

## 拆解

| 项 | 内容 |
|---|---|
| **terrain** | 四项，全部是我们引擎在算的量：<br>**玄武藏頭**（背后靠山低伏/不显）<br>**蒼龍無足**（左砂缺失或不延伸）<br>**白虎銜尸**（右砂形态凶恶、逼向穴）<br>**朱雀悲哭**（前方水声/形态不吉） |
| **liqi** | 无 |
| **rule_invoked** | 「四危以備，法當滅族」——**四项同时为负则断死**。是一条乘性/门槛式规则，不是加权求和 |
| `decision_driver` | 纯地形 |
| `outcome_claimed` | 毋丘儉 255 年败死夷族。**「不過二載」的应期与史实吻合，但记载出自其死后**，是追记 |

## 对本项目的意义

| 字段 | 值 |
|---|---|
| `testable_by_us` | **原则上可以，实际不行** —— 毋丘儉墓具体位置无定论（一说山東，一说河南），无法定位 |
| **规则形态的启示** | 这条判词是**门槛式**的：「四危以備」才断灭族，不是四项打分求和。<br>我们的引擎 v0.2 已把势/形改成乘性，但七个分量之间仍是**加权求和**。<br>本条提示：古典判词里，凶格往往是**若干项同时成立**才成立，<br>而不是各项分数低到一定程度就自动成立。这两者在数学上不等价 |
| **另一个启示** | 「白虎**銜尸**」「朱雀**悲哭**」是**形态与声音**的判断，不是有无与高低的判断。<br>我们能算「右侧有没有砂、多高、多远」，算不出「它的形态是不是凶恶」。<br>这一层落差在 `rules_luantou.yaml` 的 `not_implemented` 里已记，本条是它的最早例证 |

## 同卷相邻的两条，一并记下

**郭璞葬母（《晉書·郭璞傳》）：**
> 璞以母憂去職，卜葬地於暨陽，**去水百步許**，人以近水為言，
> 璞曰：「當即為陸矣。」其後沙漲，去墓數十里，皆為桑田。

—— 术者的判断与旁人相反，且理由是**河道演变的预测**（沙涨成陆）。
这是本批材料中唯一一条基于**地貌过程**而非静态形势的判断。

**郭璞葬龍角（同传）：**
> 帝微服往觀之，因問主人：「**何以葬龍角？此法當滅族。**」
> 主人曰：「郭璞云此葬**龍耳**，不出三年，當致天子也。」

—— 同一处地形，「龙角」与「龙耳」之别，导致「灭族」与「致天子」的相反判断。
**这是形势判断的分辨率问题的最早记载**：判断结果对形态命名极度敏感，
而形态命名本身没有客观标准。这正是我们测出「1 km 位移噪声 ≈ 效应量」的古典版本。
