# A01 · 陶振成为金诚义规划新宅

| | |
|---|---|
| 术者 | 陶振成，浙江武义陶村，时年 39 岁，家传第三代 |
| 学派 | 无门派自称。实操以形势 + 择日 + 罗盘为主，未援引玄空飞星 |
| 时间 | 2016-09-04 |
| 地点 | 浙江省武义县大溪口村（距陶村约 30 km） |
| 坐标 | 未知（论文未给，村名可定位到乡镇级） |
| 证据等级 | **A** —— 研究者全程在场观察并逐项记录 |
| 出处 | Ren, Youcao, *Feng Shui: Changing Rules and Meanings*, PhD thesis, Univ. of Sheffield, Ch.5；现场访谈记录 2016-09-04 |

## 事由

金诚义旧宅一年前已拆一半。他自述：「住老宅头几十年运气好，近年下滑。
我想是几十年过去了，运变了，得盖一栋合我新运的房子。」
他有两个女儿无儿子，长女新婚，**最大心愿是让女儿生个儿子**。

## 术者当场做了什么（按时序）

1. **召集六户邻居到场**。这不是仪式，是必要程序——邻居杨家当场提出反对：
   新宅东南角会正冲他家大门。杨家五代同堂，房子是**陶振成的父亲陶老三十三年前设计的**。
   陶必须在不否定父亲作品的前提下解决冲突。
2. **在拟建东南角放「仪式尺」（ritual ruler），读数、记录、向邻居解释读数。**
3. **换用「风水尺」定新点**：尺长 0.32 m，从原拟角点起，
   **在地上依次量放 8 次**，在第 8 次处定新点——即后退 **2.56 m**
   （论文记为「2.4 metres behind」，与 0.32×8 略有出入，原文如此，未作调整）。
4. 在新点再放仪式尺，读数、记录。
5. **在每一个可能的宅角上操罗盘**。读数确认原方案「只利金家、有害杨家」。
6. 判定：新宅整体后退 2.4 m，使宅角不再正冲杨家大门。金、杨两家当场同意。
7. **要求另一邻居金瓒改烟囱朝向**（否则正冲金诚义新宅）。该邻居立即照办。
8. 邻居们仍不尽满意，提出另一备选地块。**陶未操罗盘，只看四周**，
   判：「此地风水好，后山景色美，但**离居住中心太远，招不来那么多运气**。」——否决。
9. 现场作业毕，翻自己手抄的黄历定动土吉日。

## 判据拆解

| 项 | 内容 |
|---|---|
| **terrain（峦头）** | 只有备选地块那一次用到：「后山景色美」（正面）；决定性的却是「离居住中心远」（负面） |
| **liqi（理气）** | 罗盘读数（未言明所据流派）、仪式尺读数、黄历择日 |
| **social（社会）** | **占全部工作量的绝大部分**：邻里冲突调解、对父亲作品的避让、六户到场见证 |
| **rule_invoked** | 「大门朝向是宅中第一要事，其次是灶的朝向」「屋前远处最好有小山，主富」「离居住中心越远，运气越少」 |
| **judgment** | 后退 2.4 m；邻居改烟囱；否决备选地块 |
| **outcome_claimed** | 无。事件时点即结论时点，无应验记录 |

## `decision_driver`

**社会关系，不是地形，也不是理气。**

全案唯一被量化操作的是那把 0.32 m 的尺（放 8 次），
而它解决的是「宅角冲邻居大门」这一**几何—社会**问题。
罗盘读数的作用是**为已经谈成的方案背书**（「读数确认原方案只利金家有害杨家」）。
唯一一次纯地形判断（备选地块）里，正面的地形优点（后山美）
被负面的社会因素（离居住中心远）压倒。

## 对本项目的意义

| 字段 | 值 |
|---|---|
| `testable_by_us` | **否** |
| 原因 | 尺度错位。我们的引擎最细做到 800 m 格网，本案的决策尺度是 **2.4 m**；且核心变量（邻居大门位置、父亲旧作、族群关系）不在任何 DEM 里 |
| `maps_to_component` | 仅「屋前远处有小山主富」一句可对应 `mingtang` / 朝案分量，但本案中它未被援引为判据 |
| **反向启示** | 「离居住中心太远则运少」是一个**可计算**的量——到聚落质心的距离。它与我们全部地形分量的方向相反：我们的引擎奖励「藏风聚气」的僻静地形，而术者在此明确惩罚偏远。这是引擎与实践的一处直接冲突，值得单独验证 |
