# A07 · 廖均卿選天壽山（明永樂七年，1409）

| | |
|---|---|
| 术者 | 廖均卿，江西人，廖瑀之裔（三僚廖氏一系） |
| 时间 | 永樂七年（1409） |
| 地点 | 北京昌平縣東黃土山 → 敕封**天壽山**，即今**明十三陵**（40.29°N, 116.24°E 一带） |
| 记录等级 | **A** —— 《江西通志》，收入《古今圖書集成·堪輿部》卷679 |

## 原文

> 均卿，瑀之裔。**成祖卜壽陵，久不得吉壤。**
> 永樂七年，仁孝皇后未葬，禮部尚書趙羾引均卿至昌平縣，
> **得縣東黃土山最吉**，車駕即日臨視，定議封為天壽山，
> 命武義伯王通等董役，授均卿官。

同卷另有两条旁证：

- **游朝宗**（按《江南通志》）：「朝宗，婺源人，地理獨精，**永樂卜建天壽山，朝宗尤見褒賞**。」
- **非幻和尚**（按《衢州府志》）：「寶陀庵住僧，諳儒書，精地理，
  **嘗應召相地天壽山**，錫以金紫。永樂十八年，遣使者祭其墓。」
