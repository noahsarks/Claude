## 这是本项目一直缺的那一块

`B01` 拿到的《阳宅秘断》十七条全是**阳宅**，尺度是院落与邻屋，DEM 用不上。
**《阴宅秘断》才是阴宅（墓穴），而地形分析只在阴宅是核心业务**
（`analysis.md` 的第一条结论）。

## 体例样本

> **杨姓祖墓，亥山巳向，一运扦**
> 此局**大龙从坤来转庚酉辛直至丑艮寅而去，脉从乾方腰落开窝结穴，乾方有湖，巽方有水呈秀。**
> 仲山曰：此坟葬后，自明迄今，科甲连绵，富数十万，人丁亦盛……
> 沈注：此坟葬于明弘治，当一白正运，**局势宏敞，水光圆朗，龙真穴的**……
> 则先谨按：……**乾方有湖**，交八运殆囚不住耶。

每案给出：**来龙走向 + 入首方位 + 结穴形态 + 各方水情** + 坐向 + 元运 + 断语 + 应验 + 三家按语。

## 检验一：挨星回归 —— 通过

同 `B01`，用本项目已验证的 216 局挨星实现复算 21 案的盘。
连同《阳宅秘断》的 6 案，挨星这一层现有四个独立端点互证：
**沈氏标准表 ↔ fscalc（商业 2010s）↔ Horosa（开源 2020s）↔ 章仲山原案（1810s）**。

## 检验二：语料内部一致性 —— 这是本轮最重要的结果

**问题**：飞星格局的吉凶等级，和原文断语的正负，对得上吗？
**做法**：把 21 案按格局分三级（旺山旺向 3 / 双星 2 / 上山下水 1），
把「仲山曰」之后 300 字内的正负词做净极性，跑秩相关。
脚本 `../corpus/consistency_test.py`，可复现。

```
  旺山旺向        n= 4   正2 平0 负2   均值 +0.00
  双星到向/到坐    n=10   正3 平2 负5   均值 -0.20
  上山下水        n= 7   正0 平0 负7   均值 -1.00

  Spearman rho = +0.460, p = 0.036
  旺山旺向 vs 上山下水  Mann-Whitney 单尾 p = 0.034
```

### 先说这**不是**什么

**这不是预测效度检验。** 章仲山写断语时盘已经排好了，
一致是**构造上就该发生**的。本检验测的是：
**即使在作者可以让它对得上的条件下，它有多对得上。**

### 结果的形状：一头准，一头不准

| | |
|---|---|
| **上山下水 → 断语必负，7/7，无一例外** | 完全一致 |
| **旺山旺向 → 断语只有一半正，2/4** | **失效** |

**这个不对称才是结论。** 在一个作者本可以让它完美自洽的语料里，
「最吉」的格局有一半案例记着坏结果。

### 那一半是怎么被解释的 —— 全部靠形势

翻回原文看那两条「旺山旺向却坏」的案：

> **某姓墓，乙山辛向，五运扦**（旺山旺向）
> 仲山曰：此坟葬后，财气渐旺，**因乾兑两宫有水**；**山临五黄，主丁少**；
> 且**坎方有河冲腰**，主出寡妇。……主人曰：寡妇世世不绝。

> **严探花祖墓，辰山戌向，三运扦**（旺山旺向）
> 仲山曰：「此**地师之托词**耳，其实探花不关峰之歪，由挨星一四同官**稍涉偏歪**之故。」

修正项全部是**形势**：某方有水、某方有河冲腰、峰歪、局势宏敞、水光圆朗、龙真穴的。

王则先在《阳宅秘断》里把这层关系说破了：

> 「玄空五行之吉凶，**必与实地形峦相凑合，其验乃神**。
> ……**苟无路气直冲，甚验亦微**。」

### 于是得到一个从传统内部来的论证

> **按这批案例自己的记录，理气不足以解释结果；未解释的方差全被记在形势上。**

这是本项目做到现在，**第一个支持地形层的论证，而且它来自传统内部，不是我们外加的**。

前面所有轮次里，支持地形工作的理由要么是我们自己的假设，
要么是民族志里的孤证（A02 前方山层数）。这一条不同：
它出自这门学问最权威的案例集，由三位不同时代的注家反复确认，
且是**在理气派自己的书里、用理气派自己的失败案例**说出来的。

## 但仍不能用来检验我们的引擎

| 字段 | 值 |
|---|---|
| `testable_by_us` | **否** |
| 原因 | **21 案中只有 3 案有可定位地名**（柳塘桥、钱塘、青城桥），且都是村/桥级，落不到穴位 |
| 反差 | **21/21 都有完整的峦头描述**（来龙、入首、结穴、各方水情） |

**描述全有，坐标全无。** 这正是 `analysis.md` 补记里那条统计的又一次确认：
古人记的是「什么样」，不是「在哪里」。

### 唯一的例外与下一步

**「无锡石塘湾孙姓祖墓，子山午向，二运扦」** —— 石塘湾是无锡今存的实地名（今无锡市惠山区石塘湾），
是 21 案中定位精度最高的一条。若能找到该墓，可作为第一个
「有原始峦头描述 + 有坐标」的验证点。
但这需要地方志或田野工作，不是检索能解决的。
