# C01 · 香港中银大厦与汇丰总行（1985–1990）

| | |
|---|---|
| 涉事方 | 中国银行香港分行 / 贝聿铭（建筑师）/ 汇丰银行 / 花旗银行 |
| 时间 | 中银大厦 1985-04-18 动土，1989 竣工，1990-05-17 启用 |
| 地点 | 香港中环花园道 1 号（22.2790°N, 114.1614°E，可精确定位） |
| 证据等级 | **C** —— 事件、建筑、时间线均可查（维基、中国银行官方、观察者网等）；但风水论断部分由媒体转述，无术者具名记录 |

## 可核验的部分

- 中银大厦由贝聿铭设计，三角棱柱造型，落成时为香港及亚洲最高建筑
- 中国银行曾致电贝聿铭，对立面上众多加框巨型「X」结构表示关切，
  **贝随后把原本外露的「X」结构藏了起来** ← 这一条是可查的设计变更
- 贝聿铭长期在西方工作生活，曾公开表示不相信风水

## 转述的部分（无具名术者、无原始断语）

- 中银造型如三面刀刃的钢刀，「刀锋」正对汇丰总行
- 汇丰在楼顶加装炮台状装饰（实为起重机吊车）反击
- 花旗银行大厦采书本开页形，开口对中银尖角以挡煞

## 对本项目的意义

`testable_by_us`: **否。**

这是最著名的现代风水案例，而它**完全不含地形**。
它印证了 A04 的观察：**城市实践中，建筑替换了山水，判断是零和相对的。**
把这类案例当作「风水在现代仍然有效」的证据是错位的——
它证明的是风水作为**商业象征语言**仍然有效，而不是作为**选址方法**仍然有效。
