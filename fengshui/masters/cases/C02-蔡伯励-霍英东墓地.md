# C02 · 蔡伯励为霍英东选墓地（2006）

| | |
|---|---|
| 术者 | 蔡伯励（1922–2018），顺德真步堂第三代，携长女蔡兴华同勘 |
| 时间 | 2006 年（霍英东 2006-10-28 逝世），下葬日定于 **11 月 10 日** |
| 地点 | 香港柴湾佛教坟场，「天玄地黄」中的**「黄」部**（可定位到坟场分区） |
| 证据等级 | **C** —— 人、地、时确定且可查；踏勘细节为媒体转述 |

## 记述的作业过程

1. 带罗盘**跑遍香港**（候选集是全港，不是一处）
2. 最终选柴湾佛教坟场，理由记为：**背靠山、面朝海、左右护卫**
3. 定在「天玄地黄」的「黄」部
4. **结合霍英东的生辰八字**确定墓地地点
5. **时间上还要配合天星运转**，定下葬日 11 月 10 日

## 拆解

| 项 | 内容 |
|---|---|
| **terrain** | 背山、面海、左右护卫 —— **正是玄武/朱雀/龙虎四象，可以从 DEM 算** |
| **liqi** | 生辰八字 + 天星择日（真步堂本业是历算） |
| **social** | 家族地位与公众关注；须在公营坟场制度内选点 |
| **decision_driver** | 难以判定。记述把地形与生辰并列，但真步堂的看家本领是**历算择日**，且下葬日期被单独强调 |
| `outcome_claimed` | 无具体应验声称 |

## 对本项目的意义

| 字段 | 值 |
|---|---|
| `testable_by_us` | **部分可以。** 柴湾佛教坟场可定位，「背山面海左右护卫」四项都是我们引擎的现有分量 |
| `maps_to_component` | `xuanwu`（背山）、`water`（面海）、`hulong`（左右护卫） |
| 限制 | ① 分区级精度，落不到具体穴位 ② 这是**事后描述**，不是筛选过程的记录——所有已建成的墓地都能被这样描述一遍 ③ 候选集是「全港」，但公营坟场只有有限几处，实际自由度远小于叙述给人的印象 |

**这一条暴露了 C 级材料的通病**：术者的结论被记下来了，
但**被否决的候选**没有被记下来。没有否定样本，就无法检验判据。
