## 为什么这一案是本目录里最有用的

前面 8 个近现代案例的共同缺陷是**只有正样本**：只记下选中的点，
不记下被否决的点，因此「背山面水左右护卫」这类描述性规则无法被检验。

**这一案有否定样本，而且是两个明确的、相邻的、可定位的候选位置。**

## 原文

徐仁旺条（按《廣信府志》）：

> 仁旺，本府白雲山人，嘗表奏與丁晉公議遷定陵寢事，
> **仁旺欲用牛頭山前地，晉公定用山後地**，爭之不可。
> 仁旺乞禁繫大理，以俟三歲之驗，卒不能回。
> 仁旺表有言山後地之害云：
> **「坤水長流，災在丙午歲內；丁風直射，禍當丁未年中。」**
> 聞者初未以為然，至金人犯邊，果在丙午年，
> 而丁未以後諸郡焚如之禍，相仍不絕，東南州郡，半為盜區，其言無不驗者。

吳景鸞条（按《江西通志》），就同一处上奏：

> 未幾，因論**牛頭山山陵**章奏過直，有
> **「坤風側射，厄當國母離宮；坎水直流，禍應至尊下殿」**之語，
> 上不悅，下獄。尋以帝晏駕遇赦。後徽、欽二聖北狩，卒如其言。

## 拆解

| 项 | 内容 |
|---|---|
| **候选集** | 牛頭山**前**地 vs 牛頭山**後**地。二选一，位置明确 |
| **决策者** | 丁謂（權相），不是术者。术者的意见被否决 |
| **terrain（徐仁旺反对山後地的理由）** | ① **坤方（西南）有水长流** ② **丁方（南偏西）有风直射** |
| **terrain（吳景鸞的理由）** | ① **坤方有风侧射** ② **坎方（北）有水直流** |
| **liqi** | 有：把方位对应到干支纪年（丙午、丁未）以推应期。这一层不可计算 |
| **rule_invoked** | 未明言所据经文，但「某方有水/有风 → 主某祸」是《葬經》「藏風得水」框架的直接应用 |
| `decision_driver` | **政治**。丁謂是山陵使，徐仁旺「爭之不可」「卒不能回」，吳景鸞因言下狱 |
| `outcome_claimed` | 靖康之难（丙午 1126 金兵犯边、丁未 1127 二帝北狩） |

## 必须打的折扣

**应验部分是事后归因，而且几乎肯定是后加的。**
从 1022 年营陵到 1126 年靖康，隔一百零四年。
方志编纂于事后，「其言無不驗者」这类断语是典型的**后见之明式追记**。
干支（丙午、丁未）六十年一轮回，一百年内必然出现，命中不含信息量。

**但这不影响本案的可用性**，因为可用的不是「谁说对了」，而是：

> **两位术者在同一座山的两侧之间做选择时，各自援引了哪些具体的地形量。**

那四条判据——坤方水长流、丁方风直射、坤方风侧射、坎方水直流——
是**方位 + 地形要素 + 形态**的三元组，全部可以从 DEM 直接计算。

## 与 A05 的连接

同一批陵墓（鞏義宋陵）在 A05 中被指出是按**五音姓利**定向的：
赵姓属角音，利壬丙，故一律头枕东南、足抵西北。

**于是宋陵同时受两套互不相干的规则支配**：
朝向由姓氏声韵定死，位置在牛頭山前后之间由形势之争（和政治）决定。

这解释了为什么单纯的地形模型在这批遗址上会失败，
也说明**「朝向」与「位置」在历史实践中是两个独立决定的量**——
与 A02（坐向由生辰定、位置由山层数定）完全一致。
