# 案例拆解统计与结论

样本：8 个有内容的案例（A 级 5、C 级 3）＋ 1 个已登记未取得原文的清代案例集（B00）。
样本小，且**不是随机抽样**——它是「能找到第三方记述的全部」。
以下所有比例都只当作定性指示，不当作统计量。

---

## 一、地形在实际断验中占多大比重

| 案例 | 地形是否参与 | 是否为决定因素 |
|---|---|---|
| A01 金诚义新宅 | 边缘 | ✗ 被社会因素压倒 |
| A02 陈家墓穴 | 是 | **✓ 唯一决定量：前方山层数** |
| A03 吴莲选穴 | 是 | **✓ Google Earth 识龙脉** |
| A04 城市从业者 | ✗ 建筑替换山水 | ✗ |
| A05 北宋皇陵 | ✗ | ✗ 姓氏决定 |
| C01 中银汇丰 | ✗ | ✗ 建筑几何 |
| C02 霍英东墓 | 是（背山面海左右护卫） | ? 与生辰并列，无法判定 |
| C03 梨山合陵 | 几乎无 | ✗ 卦位决定 |

**8 案中，地形是决定因素的有 2 案（A02、A03），存疑 1 案（C02），其余 5 案地形不参与决策。**

关键分野**不是**古今，是**阴宅 vs 阳宅**：

- **两个地形决定的案例都是阴宅（选墓穴）**
- **城市阳宅案例（A04、C01）里，地形完全被建筑取代**
- 而 A04 记录了城市从业者**普遍不做阴宅**（「做不好会反噬自身」）

于是得到一个夹击结论：
> **地形分析只在阴宅业务里是核心；而阴宅业务恰恰是当代城市从业者集体回避的那一块。**

这解释了为什么我们反编译的三个软件（suangua、Horosa、fscalc）**没有一个接 DEM**：
它们服务的是城市阳宅市场，那个市场里地形没有位置。
空白是真的，但空白的形状是「阴宅工具」，不是「风水工具」。

---

## 二、坐向从哪里来 —— 一条明确的规则

| 案例 | 坐向来源 |
|---|---|
| A02 陈家墓穴 | **死者生辰**，且在踏勘之前就算好了 |
| C02 霍英东墓 | 霍英东生辰八字 |
| A04 杜金良工厂 | 商业竞争（要压过周围建筑） |
| C03 梨山合陵 | 卦位 |

**没有任何一个案例是从地形反推朝向的。**

我们的引擎目前在做的正是这件事——扫描朝向、取地形得分最高的那个。
**这与全部可查实践相反。** 坐向必须改为**必填输入**。

（此项已在 `rules_luantou.yaml` v0.11 `actions_revised` 记录，本目录是其案例依据。）

---

## 三、唯一一个可以直接落进引擎的新指标

A02 是全部材料里**唯一一次术者对地形做计数**：

> 「前方山的层数越多，风水越好。」「山有几层，代表气的强弱。」
> 选定东侧穴，**因为它面对五层山**。

而且这一案的实验设计意外地干净：三个候选穴**同排、同朝向、同尺寸（1.3×1.3 m）**，
理气、坐向、择日全部被固定，**唯一变量就是视野**。
这在民族志材料里是罕见的单变量对照。

**我们引擎现有的七个分量**
（`xuanwu / hulong / xiangbei / mingtang / water / water_gate / zangfeng`）
**没有任何一个是这个。**

拟新增 `ridge_layers`：沿朝向 ±θ 的高程剖面上，统计穿越局部极大值（山脊）的次数。
这是本目录对引擎最直接的一条输入。

## 四、材料本身的三个系统性缺陷

### ① 没有否定样本

C02 记下了蔡伯励选中柴湾佛教坟场，**没有记下他跑遍香港时否决了哪些地方**。
全部 C 级材料都是这样：只有被选中的点，没有被拒绝的点。

**只有正样本的数据集无法检验判据。** 任何描述性规则（「背山面海左右护卫」）
都能套用在任何一处已建成的墓地上。A02 是唯一的例外——它记下了三个候选和淘汰理由。

### ② 应验全是事后归因

C03「在此住了八九年，吸收长寿地灵，活到了一百岁」；
A03 吴莲以「某地方望族的成就」证明自己能力。
两者都是先有结果、再找地形解释，且只报成功案例。

### ③ 著述与实操未必一致

C03 记述者把「草庐布局**与他书上公开的布局图完全不一样**」当作正面卖点。
**这是对全部 B 级材料的直接警告**：术者书里写的规则，未必是他实际用的规则。
—— 我们此前从古籍（《葬经》《撼龙经》）提炼规则时，默认了书=实操。这个假设需要打折。

## 五、对既有结论的一次修正

前面几轮我们把「洛阳 +0.564 / 关中 −1.400」归因于模型不稳，并据此撤回了洛阳的结果。
**A05 提供了另一个解释，而且更可能是对的。**

北宋皇陵按**五音姓利**定向：赵姓属角音，利壬丙，故一律头枕东南、足抵西北，
**与「背山面水坐北朝南」正相反**。巩义宋陵就在我们采样的晋南豫北区内。

也就是说：我们的正样本里混着**至少四种不同的择址范式**——
形势派、五音姓利、政治军事考量、漕运便利——
把它们合并成同一个「风水好」的标签，等于把几个不同的目标函数平均掉。

**修正后的下一步**：单因子诊断不应把古迹一锅煮，
应先**按朝代与遗址类型分层**（陵墓/宫殿/寺观/城址；宋 vs 非宋），
再看各分量的增益在哪一层里成立。
这比继续调平滑参数或换第三个区域更有希望。

## 六、结论清单

1. **地形分析只在阴宅业务里是核心业务**（2/8 案地形决定，两案都是阴宅），
   而阴宅正是当代城市从业者回避的领域。市场空白的形状是「阴宅工具」。
2. **坐向来自生辰，不来自地形**（4 案一致，0 案反例）。引擎必须改为坐向必填。
3. **新增 `ridge_layers` 指标** —— 来自唯一一次术者对地形的计数（A02）。
4. **产品应做召回不做打分**（A03 吴莲的候选清单工作流），成功标准改为召回率。
5. **正样本需要分层**（A05 五音姓利）—— 这可能才是洛阳/关中矛盾的真正原因。
6. **最大缺口是 B00**：清代三部逐案记录体案例集（章仲山《阴阳二宅录验》、
   沈竹礽《宅断》、谈养吾《大玄空实验》）原文未取得。
   它们已经是结构化数据集，只差数字化；取得后第一件事是
   **用已验证的 216 局挨星表复算其飞星盘**，做一次跨二百年的回归测试。

---

## 七、一句自我提醒

C03 里那个「能量值 36000 分」——精确到个位，没有单位、没有量法、没有可重复性——
是当代从业者把术数伪装成测量的标本。

我们的引擎输出一个 0–1 的分数。
**如果它不能逐项给出中间量和可复核的证据，它和「36000 分」没有本质区别。**
Horosa 的 `neijuDetect` 三层诚实防线（缺输入就说缺什么、每条给坐标距离偏角、
「未检出 ≠ 无此项」）是正确做法，应当照抄。

# 补记（第二轮检索后）

第一轮结论基于 8 个案例，其中最大的方法论抱怨是「**没有否定样本**」。
第二轮找到了《欽定古今圖書集成·博物彙編·藝術典·堪輿部》全 30 卷
（公有领域，已入库 `corpus/`，42 万字），案例数从 8 增至 13，
并且**否定样本的问题被部分解决**。

## 新增 5 案改变了什么

| 案 | 新增了什么 |
|---|---|
| **A06 牛頭山之争** | **本目录第一个有否定样本的可测案例**。同一座山的前地 vs 后地，两位术者各自援引具体地形量反对山后地：坤方水长流、丁方风直射、坤方风侧射、坎方水直流。四条都可以从 DEM 算 |
| **A07 天壽山** | 「只有正样本」问题的标本：「久不得吉壤」证明有被否决的候选，但没记下来。114 条传记绝大多数是这形态——结论存，理由失 |
| **A08 永陵十八道** | 「**擇地於十八道，具圖說以進**」——全部语料中唯一记下候选数量的一案。交付物是**图 + 逐条理由**，决策者是皇帝 |
| **A09 管輅** | 四象判词的最早成条应用。凶格是**门槛式**（四项同时成立），不是加权求和 |
| **A10 呂才** | 公元 640 年的基率检验。方法与我们同类，且顺序比我们对 |

## 三条需要修正的既有结论

### ① 「产品应输出候选清单而非分数」——从一条证据变成两条，跨五百年

第一轮此结论只有 A03（吴莲的 Google Earth 候选清单）一个来源，样本 n=1。
**A08 提供了独立的第二条**：明嘉靖年间，术者的交付物是
「十八处候选 + 图说」，呈递决策者拍板。

两条证据相隔五百年、场景完全不同（帝陵 vs 民间阴宅），
但输出形态一致：**一份带理由的候选清单，交人复核。**

我们的引擎输出「经纬度 → 一个 0–1 分」。**这个形态在历史实践和当代实践里都没有对应物。**
这不再是一个可以商量的产品选择，而是一个和全部已知实践都对不上的错误设定。

### ② 凶格可能是门槛式的，不是加权求和

A09：「元武藏頭，蒼龍無足，白虎銜尸，朱雀悲哭，**四危以備**，法當滅族」。
是四项同时成立才断，不是四项分数低到某个阈值就自动成立。

引擎 v0.2 已把势/形之间改成乘性，但**七个分量之间仍是加权求和**。
加权求和会让一项极差被另几项补偿——而古典判词不允许这种补偿。
这是一个可以立即改、且有明确古典依据的结构调整。

### ③ 我们的检验顺序曾经是反的

A10 呂才的做法是：**先说清规则预言什么，再去数历史样本。**

我们在洛阳的做法是：先跑格网 → 看到 +0.564 → 再去解释为什么。
这是反的，也是后来关中给出 −1.400 时无法收场的原因。
关中复核用了正确流程（预先声明参数、不重新调参、不换区域再试），
**应把它固定为此后所有验证的强制流程**，而不是一次性的补救。

## 一条无法回避的连接：A05 + A10 + A06

- **A05**：北宋皇陵按五音姓利定向，头枕东南足抵西北，与形势通则相反。
- **A10**：五音姓利在公元 640 年就被唐代官方（呂才）以内部不自洽为由否定。
- **A06**：同一批宋陵，其**位置**又由牛頭山前后的形势之争（和政治）决定。

合起来：**巩义宋陵这批遗址，朝向由一套当时已知不成立的规则定死，
位置由另一套规则加政治斗争决定。**

我们把它们和明清陵、寺观、城址一起当作「风水好」的正样本，
然后惊讶于洛阳 +0.564 与关中 −1.400 互相矛盾。

**矛盾的来源不是模型不稳，是标签本身是几套不同规则的混合物。**
这一点第一轮已经提出（A05），第二轮由 A10 和 A06 独立确认了两次。

## 材料形态的一个统计

`corpus/bios679.json` 有 114 位堪輿家的传记。逐条看下来：

| 记录形态 | 条数（估） |
|---|---|
| 只有姓名 + 籍贯 + 著作 | 约 60 |
| 有姓名 + 地点 + 结论，**无判据** | 约 40 |
| **有明确判据（说出为什么）** | **不到 10** |
| 有判据**且**有被否决的候选 | **2**（徐仁旺 A06、郭璞葬龍角/龍耳） |

**这个分布本身就是结论**：一千多年的堪輿文献留下的是人名、地点和结论，
判据极少，可比较的候选几乎没有。

所以「用历史案例验证地形规则」这条路的上限，
不是取决于我们能找到多少材料，而是取决于**古人根本没有记录我们需要的东西**。
呂才在 640 年能做基率检验，是因为他检验的是「己亥日下葬」这种**可数的离散事件**；
而「这块地的玄武是否垂头」不是可数事件，一千四百年里也没人把它记成可数的形式。

# 补记二（第三轮：清代案例集原文到手）

第二轮的最大缺口是清代逐案记录体原文未取得（B00）。**第三轮取到了。**

《沈氏玄空学·宅斷》的**阳宅十七条 + 阴宅五十四条**原文，
经沿新浪博客「山水清澈」2017 年逐条转录本沿「前一篇/后一篇」链回溯抓取，
共 11 篇、约 6.4 万字，入库 `corpus/shen/`。
题署「无锡章仲山原著，钱塘沈竹礽详注，余王后学王则先补阐」。
三位作者均逝世逾五十年，属公有领域。

案例数由 13 增至 15（B01 阳宅十七条、B02 阴宅二十一案）。

## 做了两项检验

### 检验一：跨两百年挨星回归 —— 通过

用本项目已独立验证的 216 局挨星实现，复算章仲山原案的盘，
与原文可判读的盘面语（「双七到后」「山颠水倒」「向上双七」「旺星到向」）比对：
**下卦 6/6 一致**（两条替卦案原文自书「此局用变卦」，本实现只做下卦，不参与比对）。

挨星这一层现在有四个独立端点互证：
**沈氏标准表 ↔ fscalc（商业 2010s）↔ Horosa（开源 2020s）↔ 章仲山原案（1810s–30s）。**
可以当作已解决问题，不必再验。

它一点也没说明风水有效——只说明同一套确定性算法被正确实现了两次，相隔两百年。
顺带反衬出 suangua 那个 27.8% 的实现有多离谱（九运 24 山全错）。

### 检验二：语料内部一致性 —— 出现了本轮唯一一个支持地形层的论证

把《阴宅秘断》21 案按格局分三级，与「仲山曰」之后的断语正负做秩相关
（脚本 `corpus/consistency_test.py`）：

```
  旺山旺向        n= 4   正2 平0 负2   均值 +0.00
  双星到向/到坐    n=10   正3 平2 负5   均值 -0.20
  上山下水        n= 7   正0 平0 负7   均值 -1.00
  Spearman rho = +0.460, p = 0.036
```

**这不是预测效度检验。** 章仲山写断语时盘已排好，一致是构造上就该发生的。
它测的是：**即使在作者可以让它对得上的条件下，它有多对得上。**

结果的形状是**一头准、一头不准**：

- **上山下水 → 断语必负，7/7，无一例外**
- **旺山旺向 → 断语只有一半正，2/4**

**这个不对称才是结论。** 在一个作者本可以让它完美自洽的语料里，
「最吉」的格局有一半案例记着坏结果。

翻回原文看那两条「旺山旺向却坏」的案，修正项**全部是形势**：
「乾兑两宫有水」「山临五黄」「坎方有河冲腰」「峰歪」，
以及正面案里的「局势宏敞，水光圆朗，龙真穴的」。

王则先把这层关系说破了：

> 「玄空五行之吉凶，**必与实地形峦相凑合，其验乃神**……**苟无路气直冲，甚验亦微**。」

于是：

> **按这批案例自己的记录，理气不足以解释结果；未解释的方差全被记在形势上。**

**这是本项目做到现在，第一个支持地形层的论证，而且它来自传统内部。**
此前支持地形工作的理由要么是我们自己的假设，要么是民族志孤证（A02 前方山层数）。
这一条不同：它出自这门学问最权威的案例集，由三位不同时代的注家反复确认，
且是**在理气派自己的书里、用理气派自己的失败案例**说出来的。

## 但它仍然不能用来检验我们的引擎

| | |
|---|---|
| **21/21 都有完整峦头描述** | 来龙走向、入首方位、结穴形态、各方水情 |
| **只有 3/21 有可定位地名** | 柳塘桥、钱塘、青城桥，均为村/桥级，落不到穴位 |

**描述全有，坐标全无。**

这与 A06（有坐标 + 可计算判据 + 否定样本，但判据只四条）合起来，
就是这条路的天花板：

> **判据与坐标在历史文献里几乎从不同时出现。**

唯一的例外是「**无锡石塘湾孙姓祖墓，子山午向，二运扦**」——
石塘湾是今无锡市惠山区的实存地名，是 21 案中定位精度最高的一条。
若能找到该墓，就是第一个「有原始峦头描述 + 有坐标」的验证点。
但这需要地方志或田野工作，不是检索能解决的。

## 三轮下来，结论清单的净变化

| 结论 | 第一轮 | 第三轮 |
|---|---|---|
| 地形只在阴宅是核心 | 2/8 案支持 | **第四次确认**（清代案例集主体也是阴宅有峦头、阳宅无地形） |
| 坐向来自生辰不来自地形 | 4 案一致 | 不变 |
| 产品应输出候选清单而非分数 | n=1（吴莲） | **n=2**（+ 駱用卿十八道，相隔五百年） |
| 凶格是门槛式不是加权求和 | — | 新增（A09） |
| 正样本标签是混合物 | 提出（A05） | **三重确认**（+A10 +A06） |
