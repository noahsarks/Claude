## 二、为什么这批材料比预想的更有用

**① 它含有带地点的案例，而且有被否决的候选。**
此前拆解 8 个近现代案例时，最大的方法论问题是「只有正样本，没有否定样本」。
本批材料里至少三处提供了否定样本：

- **牛頭山之爭（北宋，永定陵）**：徐仁旺主張用**山前**地，丁謂定用**山後**地，
  爭執不下。徐的反對理由是可计算的方位判断：
  「坤水長流，災在丙午歲內；丁風直射，禍當丁未年中。」
  吳景鸞对同一处的判词：「坤風側射，厄當國母離宮；坎水直流，禍應至尊下殿。」
  —— **同一处山，两个候选位置，各自的理由用的正是本引擎计算的量（坤方水、丁方风、坎方水）。**
- **駱用卿選永陵（明嘉靖）**：「擇地於**十八道**，具圖說以進，遂用之，即永陵是也。」
  —— 十八个候选，选了一个。候选集大小已知。
- **廖均卿選天壽山（明永樂七年 1409）**：「成祖卜壽陵，久不得吉壤……
  引均卿至昌平縣，得縣**東黃土山**最吉」—— 即今明十三陵，坐标确定。

**② 它含有中国自己的、比我们早一千四百年的同类检验。**

唐·呂才《五行祿命葬書論》（本目录 `yiwen.txt`）不是哲学式的反对，
而是**用历史记录做基率检验**：

> 「今檢葬書，以己亥之日用葬最凶。謹按春秋之際，此日葬者凡有二十餘件，
> 此則葬不擇日，其義二也。」

即：术书说己亥日下葬最凶；查春秋一代，此日下葬者二十余例；
故下葬不择日。——**这就是数一遍历史样本、看禁忌是否被遵守的基率检验**，
与我们做的 Kvamme 增益检验是同一类推理，公元 640 年前后完成。

他对**五姓（五音姓利）**的证伪同样是实证的：五姓之说要求姓氏与宫商角徵羽对应，
但（a）经典中无此说；（b）后世赐姓极多，管蔡郕霍魯衛毛聃等皆姬姓分出，
无从配属；（c）《春秋》中陳衛秦同为水姓、齊陳宋皆为火姓，
「或承所出之祖，或繫于所屬之星，或取所居之地」——同一套姓氏在不同经典里归属不同。

**这一点直接接上 A05（北宋皇陵按五音姓利定向）**：
决定巩义宋陵朝向的那套方法，在它被用于皇陵之前四百年，就已被唐代官方否定过。

**③ 它把「批判风水」确立为这个传统的内部组成部分。**
藝文一整卷（1.86 万字）全是反对与质疑的文章，且被收进钦定官修类书。
这说明「风水是否有效」的争论不是现代或西方引入的，而是这门学问自身的一部分。
本项目做的事情因此不是外来的祛魅，而是这条内部批判线的延续。
