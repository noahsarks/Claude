# 抓取过程留下的索引文件

这些不是研究材料，是**抓取过程的可复核记录**，留着是为了让别人能验证语料是怎么来的。

| 文件 | 内容 |
|---|---|
| `sina_all.json` | 新浪博客「山水清澈」全部博文目录抓取结果（匿名只放出约十页，共 250 条） |
| `shen_index.json` | 从上表筛出的《沈氏玄空学》连载篇目 |
| `shen_found_fwd.json` | 沿「后一篇」链正向游走时命中的篇目与标题 |

## 为什么要沿链游走

新浪博客的文章目录（`articlelist_<uid>_0_<page>.html`）对匿名访问只返回前约十页，
更深的页码返回空模板（实测 p50/p100/p150 均为 16 KB 的空壳）。
该博客共 191 页、约九千篇，《沈氏玄空学》连载在 2017 年，落在目录取不到的区间。

所以改为：从已知一篇出发，沿页面底部的「前一篇 / 后一篇」链逐篇走，
按标题筛出连载。连载与日更八字文章交错，命中率约 1/32，
前后共走约一千二百步，取到 68 篇。脚本见 `../masters/corpus/fetch/`。
